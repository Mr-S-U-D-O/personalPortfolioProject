## Why this matters

The contact form, project links, and footer navigation are the three primary conversion paths on this portfolio site. All three are currently broken:

1. The EmailJS CDN URL is corrupted by the build script's cache-busting regex, so the contact form JavaScript library never loads — the form silently fails on submission.
2. Three GitHub "View Source" links use `Mr-S.U.D.O` (periods instead of hyphens) which is a 404 on GitHub.
3. One "View Source" link literally says `/* Add GitHub repository link here */` as its href.
4. Every footer navigation link on index.html uses `../` prefix which resolves above the site root — all footer links are 404s.
5. All project card images use `../projects/...` paths from root-level pages — images don't load.
6. The `data-tooltip` for Node.js contains the cache-bust string: "Node.min.js?v=1773556329307".

These are not cosmetic issues. A hiring manager clicking "View Source" or "Contact" will hit errors immediately.

## Current state

### 1. Broken EmailJS CDN URL

**File**: `index.html`, line 88

```html
<script type="text/javascript" src="https://cdn.js?v=1773556329307delivr.net/npm/@emailjs/browser@4/dist/email.min.js?v=1773556329307"></script>
```

The build script's cache-busting regex matched `.js` inside the CDN URL and injected `?v=TIMESTAMP` after it, breaking the domain name. The correct URL should be:

```
https://cdn.jsdelivr.net/npm/@emailjs/browser@4/dist/email.min.js
```
